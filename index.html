Letter Order

The numbers show each letter's rank in A to Z order. Decode them in sequence to find the hidden word.

How to play

You get a number code. Each number is where that letter lands when all the letters of the hidden word are sorted A to Z.

Example: apple sorted is a, e, l, p, p, so a=1, p=4, p=5, l=3, e=2.

1 4 5 3 2

Type a word that fits the code exactly. Then check the colors:

Green: correct letter

Yellow: the letter is in the word, wrong spot

Blue: the right letter is within 3 letters backward or forward of this letter

Purple: a combination of yellow and blue

Grey: the letter does not exist in the word
